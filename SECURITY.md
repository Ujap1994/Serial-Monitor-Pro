# Security Policy

Please report security issues **privately** via
[GitHub Security Advisories](https://github.com/Ujap1994/Serial-Monitor-Pro/security/advisories/new)
or by e-mail to info@pwsohasolutions.com – not in public issues.

Only the latest release receives fixes. Serial Monitor Pro does not open network ports and does not
send data anywhere; it only accesses the serial ports you select and the files you save.
